# founder-charts

Use the user's project working directory. Inputs: project context, state, existing
artifacts and the requested outcome. Missing blocking evidence stays explicit.

Read standards/charts.md relative to the central framework when chart semantics, styles or review criteria are needed. Read standards/ui.md for UI behavior. Use existing tokens and libraries; chart type follows the data question. Verify zeros versus missing values, scales, units, keyboard/touch access and reduced motion.

Read [workflow](../../../workflows/design.md) and
[quality](../../../standards/quality.md) as relevant. Follow current authorization;
this skill grants no additional permissions or agent delegation.

Expected result: correct chart choice, preserved values and checked interaction. Save enduring decisions and actual checks in project
context/state/handoff; keep temporary diagnostics out of long-term context.
