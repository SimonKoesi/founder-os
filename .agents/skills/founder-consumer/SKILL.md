# founder-consumer

Work in the user's project, never write project output into the framework.
Read [the method](method.md) for inputs, procedure, artifacts and acceptance checks.
Resolve `<skill-directory>` to this directory; run tools from the project working
directory using absolute script paths. Use `python` on Windows.
Read [evidence rules](../../../standards/evidence.md) when producing research,
projections or claims. Missing inputs stay unknown; request only blocking facts.
Preserve existing artifacts and pitch history. End with confirmed outputs,
evidence limits and the next decision. A recommended next skill is optional.
