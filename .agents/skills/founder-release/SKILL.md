# founder-release

Use the user's project working directory. Inputs: project context, state, existing
artifacts and the requested outcome. Missing blocking evidence stays explicit.

Read current changes, checks, target environment and authorization. Choose deployment, operation or archive workflow to fit the requested outcome. Prepare backups, health checks and rollback. Execute only authorized external actions and confirm the resulting state. Keep failed attempts recoverable.

Read [workflow](../../../workflows/deployment.md) and
[quality](../../../standards/quality.md) as relevant. Follow current authorization;
this skill grants no additional permissions or agent delegation.

Expected result: reviewable release or operations plan, verified outcomes and rollback. Save enduring decisions and actual checks in project
context/state/handoff; keep temporary diagnostics out of long-term context.
