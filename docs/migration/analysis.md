# Discovery and transformation

All 33 locally present source files, including two hidden Claude manifests and
the ignore file, were read in full. All were UTF-8 readable; no inaccessible file
was omitted. External/missing references in ELEMENTE were deliberately ignored.
[The exhaustive mapping](source-to-target.json) records each path, byte count,
SHA-256, purpose, target(s), status and disposition. Full original bytes are in
the ignored local archive; the source directory itself was not edited.

## Functions and relationships

Eleven business skills share `founder/idea.md` and progressively produce board,
competition, simulated panel, price, offer, finance, marketing, brand, operations,
launch and compiled plan. Panel answers feed pricing and messaging. CFO costs feed
offer and pricing; real supplier costs can revise finance. The compiler imports
the CFO module by sibling path; sibling layout is preserved. Four executable tools
and synthetic examples remain paired with their methods. Tool tests retain the
dynamic loader adapted to `.agents/skills`.

README duplicates workflow/output descriptions and installation guidance. Manifests
repeat branding, author and distribution metadata. `test_repo.py` primarily asserts
Claude marketing copy, exact eleven-skill count, long descriptions and punctuation;
it is replaced by functional/integrity tests. Existing functional tests are retained.
The UI element index contains eleven behavioral contracts and references unavailable
files; the contracts are preserved without following those links. The chart document
contains both semantic rules and optional visual presets; full detail is centralized
under standards/charts. Ponytail contributes reuse/minimal-change reasoning.

## Resolved contradictions and removals

| Source behavior | Resolution |
| --- | --- |
| Eleven skills in mandatory chain | Advisory sequence; routes/phase/risk choose only useful steps |
| Board requires a Claude Agent tool; consumer assumes ten parallel agents | Separate lenses in-session; independent panel execution only with authorization and available tools |
| Simulated buy rate called an upper bound | No calibrated bound claimed; real demand remains separately unverified |
| Numeric model could return Profitable with absent panel | Passing financial checks with missing buyer evidence returns Incomplete; even Profitable is only a model verdict |
| All coding invokes persistent Ponytail persona | Shared small-complete-change standard; no session hijack or compulsory closing copy |
| Large descriptions/line counts enforced by tests | Short discriminating entrypoints and conditional method detail |
| Claude slash/macros/manifests | Codex SKILL frontmatter/discovery and explicit resolved paths |
| UI index points to missing external/local components | Preserve the available behavior; no invented widgets or downloaded implementation |
| Premium visuals might suggest automatic decorative chart replacement | Data semantics/accessibility and project design remain authoritative |

No business method is discarded. Methods are retained almost in full with explicit
platform/authorization corrections; repeated workflow routing is now centralized
but original next-step suggestions remain advisory historical method guidance.
User supplements are retained with the owner's explicit rights confirmation in NOTICE.
The top-level source documents' absolute paths and account details are not shipped.

## New components and gaps addressed

Added compact central router, task routing table, ownership of persistent state,
five software/context skills, adaptive lifecycle, quality/security/evidence standards,
project profiles, transactional initialization/adoption, immutable release installation,
version+digest binding, previewed updates, validation, targeted regressions, GitHub
templates/CI and explicit handoff/publication documentation. This closes the source's
software development, data safety, version drift, maintenance and cross-project gaps.
Business funding and sales are covered in strategy/launch without inventing a
CRM, bank integration or unauthorized external outreach.

Known limits: no current market/business facts researched during a local-only
content migration; no live buyer agents; no production deployment. Initial sandboxed
gh authentication failed; an authorized check outside the sandbox confirmed valid
authentication. The owner confirmed all source rights. The authenticated gh lookup
found no repository at the requested owner/name before creation. See publishing notes.
