# Smallest complete change

Read the touched implementation, callers, configuration and tests. Reuse the
project's components, then platform/standard library, then installed dependencies.
Add abstractions and options only for a demonstrated requirement. Prefer clear
code to cryptic brevity. Keep validation, data protection, accessibility and
meaningful regression checks. Finish all requested behavior and affected callers.
For optional deeper rationale read [Ponytail reference](simplicity-reference.md);
its persona, slash modes and session persistence are historical, not active rules.
